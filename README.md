# Dream XI

A FIFA Ultimate Team-style draft game built with Angular 22 + Angular Material:
pick a formation, draft one player per slot from 5 real-World-Cup-squad
candidates at a time, then simulate a match with your finished XI.

## Setup

These files are meant to drop into a fresh Angular 22 + Material project,
rather than being a full standalone project (no `package.json`/`angular.json`
included, since those are best generated by the CLI for your exact
environment).

```bash
# 1. Scaffold a new project
ng new dream-xi --style=scss --routing=false --zoneless

# 2. Add Material
cd dream-xi
ng add @angular/material
# pick a theme (e.g. Green) when prompted, and say yes to typography/animations

# 3. Copy this repo's src/app and src/styles.scss over the generated ones,
#    replacing app.component.* and src/main.ts, src/app.config.ts

# 4. Run it
ng serve
```

## How it works

- **`core/services/worldcup-data.service.ts`** — streams the Fjelstul World
  Cup Database CSVs (squads, appearances, goals, awards, matches) via five
  `httpResource.text()`s and aggregates them into one payload per
  (team, edition) plus a flat rating-enriched player pool. Men's editions
  1930–2022.
- **`core/utils/ratings.ts` + `core/data/legendary.ts`** — ratings are
  derived from real per-tournament performance (apps, goals, stage reached,
  awards, champion) through a 44–96 curve, then a curated overlay pins the
  all-time greats (Pelé 1970 → 96, Zoff 1982 → 93, …).
- **`core/services/draft.service.ts`** — the whole game state machine:
  `formation → drafting (slot by slot) → complete`, all plain signals.
- **`core/services/simulation.service.ts`** — simple strength-diff based
  match simulator using average squad rating + a "chemistry" bonus for
  same-nation players.
- **`app.component.ts`** — switches between the three phase components
  using the new `@switch` control-flow syntax, driven by `draft.phase()`.

## Known rough edges to fix as you build

- Data ships over the network from GitHub raw on first load — no offline
  cache. A `service worker`/`localStorage` snapshot is a natural next step.
- No persistence — reloading the page always restarts the draft. Could store
  `draft.squad()` in `localStorage` via an `effect()`.
- No loading state per-candidate-pool reroll (only the initial full-pool
  fetch shows a spinner) — negligible since reroll is just a local reshuffle.
- Formations are hardcoded in `core/data/formations.ts` — add more or tweak
  pitch coordinates freely, nothing else needs to change.
- `core/data/legendary.ts` is a curated overlay — extend it (keyed by
  Fjelstul `family_name` + `team_code` + edition) to pin more all-timers.

## Ideas to extend

- Add a countdown timer per pick for FUT-style pressure.
- Add rarity tiers (e.g. gold/legend based on rating thresholds) with
  different card art via `mat-card` color variants.
- Persist the current XI and show a "campaign" of consecutive simulated
  matches instead of just one.
- Let the user pick which World Cup eras are in the pool before drafting
  (already supported at the data layer via `WorldCupDataService.years`).
